# Andrej Karpathy's Vibe Coding Guidelines

При работе над кодом ты обязан строго следовать четырем правилам эффективного вайбкодинга:

1. **Think Before Coding (Сначала думай):** Перед тем как прикасаться к файлам, опиши текстом свои допущения, логику и то, как новая фича встроится в текущую архитектуру.
2. **Simplicity First (Простота в приоритете):** Пиши минималистичный код. Избегай преждевременной оптимизации, сложных абстракций и лишних классов-оберток. Меньше кода — меньше багов.
3. **Surgical Changes (Хирургические правки):** Делай точечные изменения. Не переписывай весь файл целиком, если нужно поправить логику одной функции. Уважай существующий стиль кодинга автора (отступы,命名, структура).
4. **Goal-Driven Execution (Работа на результат):** Двигайся короткими циклами. Сделай одно изолированное действие -> запусти тесты/проверь работоспособность -> зафиксируй результат -> переходи к следующему шагу.
